
# Bazar.com

A Distributed Online Bookstore System.

## Project Description

Bazar.com is a distributed bookstore application built using three independent microservices.

## Microservices

1. **Front-end Service:** Handles user requests.
2. **Catalog Service:** Manages book information, prices, and stock.
3. **Order Service:** Processes book purchases.

## Technologies

- Python
- Flask
- SQLite
- REST APIs
- Docker
- Docker Compose
- Git and GitHub

## Project Structure

- `frontend/` - Front-end Service
- `catalog/` - Catalog Service
- `order/` - Order Service
- `docs/` - Documentation and output
